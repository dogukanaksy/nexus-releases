# nexus-releases

**NexusExe** mağaza kurulum aracının derlenmiş sürümlerinin (release binaries) dağıtıldığı repo.

NexusExe, Toshiba GeniusOpen kullanan mağazalarda POS, mağaza bilgisayarı ve servis kurulumlarını otomatikleştiren bir C# / .NET masaüstü uygulamasıdır. Kaynak kodu özeldir. Projenin tanıtımı ve sonuçları için vitrin reposuna bakabilirsiniz.

## İndirme

Güncel sürüm için [Releases](../../releases) sayfasını kullanın.
